# Survival Zombie 3D Demo

This repository contains a single-page animated zombie survival scene inspired by cinematic 3D horror visuals.

## Run locally

From the repository root:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Files

- `index.html` — main scene structure
- `style.css` — visual design and 3D animation styling
- `script.js` — random zombie generation and motion loop

## Notes

The animation is fully self-contained and uses no external libraries.
It is optimized for quick local preview in a browser.
